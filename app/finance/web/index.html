Format Kode Transaksi

Dibuat otomatis. Urutan dimulai dari 000001 untuk setiap account type di setiap bulan (bulan mengikuti tanggal transaksi). Kode tidak bisa diubah.
TB-202611-000001 B kode account · 202611 tahun & bulan · 000001 nomor urut
🏦BankTB-202611-000001
💵CashTC-202611-000001
📱E-MoneyTE-202611-000001
Transaksi lama (sebelum V2) tidak punya kode dan tampil "—"; dianggap account Bank.

Tentang

Finance App v2.1 · Data tersinkronisasi otomatis ke cloud (Firebase) — transaksi & rencana tersimpan di server dan langsung update di semua perangkat. Preferensi tema disimpan di perangkat ini.
