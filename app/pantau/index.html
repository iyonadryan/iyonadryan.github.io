Iyon App

Cara Hitung

Pemakaian = selisih antar dua catatan, lalu dibagi rata ke rentang waktu di antaranya (mis. catatan Senin 20:00 → Rabu 08:00 dibagi ke Senin, Selasa, & Rabu sesuai jamnya). Makin sering mencatat, makin akurat analisis per hari & per waktu. Untuk item jenis Sisa, kalau barusan isi ulang (beli token), isi kolom “Isi ulang” supaya pemakaiannya tetap terhitung.

Tentang

Pantau App v0.1 · Data tersinkronisasi otomatis ke cloud (Firebase) — item & catatan tersimpan di server dan langsung update di semua perangkat. Preferensi tema disimpan di perangkat ini.
